# LuckyAgent Ops visual assets

All raster files live here and ship with the `/ops/` static build. Do not copy them into the Android APK or the local theme sample library.

| File | Slot | Prompt / source |
| --- | --- | --- |
| `login-hero.webp` | Login full-bleed atmosphere | Cinematic dark operations deck, obsidian floor, lime rim light, volumetric haze, film grain. No text, no UI, no watermark. |
| `cover-themes.webp` | Home bento · 主题管理 | Floating 9:16 theme plates in a black gallery, acid-lime rim, editorial still life. No letters. |
| `cover-prompts.webp` | Home bento · Prompt | Glass manuscript sheets and a fountain pen in a black void, amber page light. No readable words. |
| `cover-skills.webp` | Home bento · Skills | Interlocking brushed-steel modules as a skill kit, smoked glass, lime edge light. |
| `cover-pets.webp` | Home bento · Pets | Original obsidian fox-like sculpture on a lacquer cube. Not a branded character. |
| `empty-soon.webp` | Coming soon / empty | Sealed glass vault, lime lock ring, dust and volume light. |

Art direction: Linear density + Vercel black + Awwwards spatial light. Accent `#c7f082`. Nav glyphs and the LuckyAgent mark are inline SVG in `App.jsx` so they stay sharp and themeable.
